A single one-line patch note for make.fun's "Real-Life Patch Notes: The Comedy Changelog" bounty: a terse release note for the bug where the brain replays your most embarrassing moment from 2009 in 4K on loop at bedtime. The program validates the line (one line, at most 160 characters) and writes it to `/output/entry.txt`.

## Run it

```sh
node main.ts
```
